# Third-Party Components

## AndroidX (Core, Activity, Compose, Navigation, Lifecycle)
- **License**: Apache 2.0
- **Used for**: Android platform libraries, Jetpack Compose UI, Navigation

## AndroidX Media3 (ExoPlayer)
- **License**: Apache 2.0
- **Used for**: Audio playback, MediaLibraryService, Android Auto support

## AndroidX Room
- **License**: Apache 2.0
- **Used for**: Local SQLite database (tracks cache, play history, queue, settings)

## AndroidX WorkManager
- **License**: Apache 2.0
- **Used for**: Background sync scheduling

## AndroidX Paging
- **License**: Apache 2.0
- **Used for**: Paginated display of synced tracks

- **License**: Apache 2.0
- **Used for**: EncryptedSharedPreferences for auth token storage

- **Used for**: JSON serialization of sync protocol DTOs

## Koin
