# Michi Music Mobile — Stability Audit (F-Droid / FLOSS Release Candidate)

| ID | Severity | Component | Root Cause | Fix Description | Verification | Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **AUD-01** | P0 Critical | `:player` | 29 lint errors on Media3 `UnsafeOptInUsageError` for `UnstableApi` classes (`BaseAudioProcessor`, `AudioProcessor`, `DefaultAudioSink`, `RenderersFactory`). | Explicitly annotated classes/methods with `@OptIn(UnstableApi::class)` on minimal appropriate scopes in `PlayerController` and `ReplayGainAudioProcessor`. | `./gradlew :player:lintDebug` and `./gradlew lint` -> **PASS (0 errors)**. | **RESOLVED** |
| **AUD-02** | P0 Critical | `:player` | `PlayerController` created ad-hoc unmanaged coroutine scopes on `Dispatchers.Main` for position updates without cancellation on `release()`. | Replaced with `SupervisorJob()` and `controllerScope = CoroutineScope(controllerJob + Dispatchers.Main.immediate)` with explicit `controllerJob.cancel()` and `player.release()`. | Unit tests & compilation -> **PASS**. | **RESOLVED** |
| **AUD-03** | P1 High | `:player` | Silent catch blocks in `AudioSink` and `RenderersFactory` fallback initialization hiding diagnostic telemetry. | Added explicit Android `Log.w`/`Log.e` diagnostics with exception traces during audio sink and renderers fallback. | Lint & runtime logs -> **PASS**. | **RESOLVED** |
| **AUD-04** | P1 High | `:player` | Audio becoming noisy (headphone disconnection or Bluetooth off) was not automatically handled by ExoPlayer. | Configured `.setHandleAudioBecomingNoisy(true)` on `ExoPlayer.Builder` in `PlayerController`. | Media3 build & unit tests -> **PASS**. | **RESOLVED** |
| **AUD-05** | P1 High | `:player` | Possible numeric instability (NaN / Infinite amplification) on malformed ReplayGain metadata tags. | Hardened gain computation with `volume.isNaN() || volume.isInfinite() || volume < 0f` sanitization. | `testDebugUnitTest` -> **PASS**. | **RESOLVED** |
| **AUD-06** | P0 Critical | `CI/CD` | `.github/workflows/ci.yml` was monolithic, sequential, and only ran tests for `michi-link-client`. | Refactored into parallel independent jobs (`lint`, `unit-tests-normal`, `unit-tests-fdroid`, `build-normal`, `build-fdroid`) with a mandatory `quality-gate`. | CI pipeline YAML syntax and local task execution -> **PASS**. | **RESOLVED** |
| **AUD-07** | P1 High | `:app` | `SyncedTracksViewModelTest` suffered from `UncaughtExceptionsBeforeTest` due to eager coroutine scope binding before test dispatchers. | Isolated ViewModel instantiation within `runTest(testDispatcher)` per test case. | `./gradlew test` -> **PASS (100% test success)**. | **RESOLVED** |
| **AUD-08** | P0 Critical | `:app` | `assembleNormalRelease` and `assembleFdroidRelease` failed when building without local `keystore.properties`. | Added graceful fallback to debug signing config when release keystore is absent in CI/dev environments. | `assembleNormalRelease` & `assembleFdroidRelease` -> **PASS**. | **RESOLVED** |
| **AUD-09** | P2 Medium | `:app` | Missing automated instrumentation / smoke navigation test suite. | Added `SmokeNavigationTest.kt` under `app/src/androidTest` covering MainActivity, BottomNavBar, Library, NowPlaying, Remote, Sync, and Settings. | `./gradlew assembleDebugAndroidTest` -> **PASS**. | **RESOLVED** |
